# 📸 Instagram Non-Followers Finder

Una aplicación web moderna para identificar quién no te sigue de vuelta en Instagram, con medidas de seguridad avanzadas para minimizar riesgos.

## 🚀 Características

- ✨ **Interfaz moderna** con diseño glassmorphism
- 🔒 **Medidas de seguridad avanzadas**:
  - Delays aleatorios entre acciones
  - Rotación de User-Agents
  - Rate limiting estricto
  - Pausas largas periódicas
  - Simulación de comportamiento humano
- 📊 **Estadísticas visuales** de seguidores, seguidos y no seguidores
- 💾 **Exportación a JSON** de la lista completa
- 🎯 **Límites seguros**: Máximo 80 acciones/hora, 400/día

## 📋 Requisitos

- Python 3.8 o superior
- pip (gestor de paquetes de Python)
